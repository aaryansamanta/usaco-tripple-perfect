# 🥉 Bronze

Three warm-up-to-intermediate problems. Bronze rewards clean thinking over heavy machinery: a parity identity, a bitmask over 2²⁰ boards, and a greedy on powers of two.

| # | Problem | Core idea | Complexity | Notes |
|---|---------|-----------|-----------|-------|
| 1 | [It's Mooin' Time IV](1-mooin-time-iv/) | Suffix XOR is invertible, so the answer is always YES | O(N) | [solution](1-mooin-time-iv/solution.cpp) |
| 2 | [Moo Hunt](2-moo-hunt/) | Group moves by first cell, subset-sum DP over masks | O(N²·2ᴺ) | [solution](2-moo-hunt/solution.cpp) |
| 3 | [Purchasing Milk](3-purchasing-milk/) | Normalise prices, then greedy on binary representation | O(N + 31Q) | [solution](3-purchasing-milk/solution.cpp) |

**Suggested order:** 1 → 3 → 2.
